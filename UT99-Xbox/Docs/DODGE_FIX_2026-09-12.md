# Y-button dodge direction fix

Issue #9 reported reversed left/right Y-button dodging. XboxDodgeDirectionFromStick now matches the stock PlayerPawn double-tap strafe convention: positive strafe uses DODGE_Left, whose script implementation applies positive local Y velocity. Forward/back, deadzone, axis priority, and script double-tap handling are unchanged. No .u package changes are needed.
