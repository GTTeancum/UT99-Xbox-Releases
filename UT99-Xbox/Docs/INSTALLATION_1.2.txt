Unreal Tournament Xbox v1.2 - Installation
==========================================================

This is the full v1.2 release, not a patch.

Requirements
------------

- A modded original Xbox capable of launching unsigned XBE files.
- A legally owned Unreal Tournament Game of the Year PC installation.

Installation
------------

1. Create a clean `UnrealTournament` folder on the Xbox.
2. Copy every file and folder from this release into that folder.
3. From your PC GOTY installation, copy these four asset folders into the same
   Xbox folder and merge them with the included folders:
   - Maps
   - Music
   - Sounds
   - Textures
4. Launch `default.xbe`.

Do not copy the PC `System` folder. This release includes the correct Xbox
System files, configuration, menus, community packages, and executable.
Replacing them with files from another build can cause startup failures or
content mismatches.

The first press of Start after the intro flyby opens profile selection. Create
or load a profile to enter the main menu.

Updating an existing installation
---------------------------------

Install v1.2 into a clean folder, then copy the four owned PC asset folders
listed above. Do not copy an older release's System folder or configuration
files over this release.

Widescreen
----------

Widescreen follows the Xbox dashboard's video setting automatically. There is
no separate aspect-ratio option in the game. Widescreen uses 480p when available
and falls back to 480i. Single-player uses the wider view; split-screen uses
a centered 4:3 picture with side borders. 720p and 1080i are not used.
